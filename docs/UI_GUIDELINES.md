# RepairVerse AI - UI Guidelines

## 1. Design Philosophy

RepairVerse AI should feel like a premium AI SaaS platform.

The UI should combine:

- Apple
- Linear
- Vercel
- Stripe
- Arc Browser

Design Principles:

- Minimal
- Elegant
- Premium
- Spacious
- Smooth
- Trustworthy
- Eco-friendly

The interface should immediately communicate innovation and sustainability.

---

# 2. Design Language

Primary Style:

Glassmorphism 2.0

Characteristics:

- Frosted Glass
- Background Blur
- Transparent Layers
- Soft Shadows
- Floating Cards
- Rounded Corners
- Gradient Highlights
- Smooth Animations

Avoid:

- Flat cards
- Heavy borders
- Harsh colors
- Boxy layouts
- Cluttered dashboards
